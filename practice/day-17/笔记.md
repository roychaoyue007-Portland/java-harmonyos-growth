# Day 17 练习笔记：开发环境组成

## 1. 今日主题

开发环境组成：工具、运行时、项目目录、配置与本地服务。

今天接在 Day15 和 Day16 后面：Day15 讲程序怎么启动，Day16 讲程序运行需要哪些条件，Day17 把这些条件放到“开发环境”里统一理解。

## 2. 核心主线

```text
操作系统
↓
打开编辑器或 IDE
↓
进入项目目录
↓
开发工具识别代码、配置和依赖
↓
Shell 根据 PATH 找到语言工具或运行工具
↓
工具读取参数、配置文件、环境变量
↓
程序启动成进程
↓
如果是服务程序，监听本地端口
↓
通过 localhost:端口 访问
```

## 3. 开发环境的组成

| 组成部分 | 我现在的理解 |
| --- | --- |
| 操作系统 | 管理程序、进程、文件、权限和端口 |
| 编辑器 | 用来编辑代码 |
| IDE | 集成编辑、识别项目、运行、调试等能力 |
| 语言工具 | 处理代码或启动程序，例如 `java`、`javac` |
| 运行时 | 支撑程序运行，例如 JVM |
| 项目目录 | 代码、配置、资源和依赖所在的位置 |
| 配置文件 | 告诉项目或程序怎么工作 |
| 环境变量 | 给系统和程序提供环境级信息，PATH 负责命令查找 |
| 本地服务 | 在当前电脑上运行并监听端口的服务程序 |
| 日志 | 记录运行过程和错误线索 |

## 4. 今日重点修正

1. 语言工具不是代码编辑环境，而是处理代码或启动程序的工具。
2. 运行时不是编辑器，它支撑程序真正运行。
3. 项目目录会影响工具查找代码、配置、依赖和相对路径。
4. `localhost:8080` 表示当前电脑上 8080 端口对应的服务入口。
5. 从打开开发工具到本地服务启动的完整链路，需要在 Week03 复习时重点回看。

## 5. 建议观察命令

```powershell
Get-Location
Get-ChildItem .
Get-Command java
java -version
$env:PATH
$env:JAVA_HOME
Get-NetTCPConnection -State Listen | Select-Object -First 10
```

观察重点：

- 当前目录会影响项目识别和相对路径。
- PATH 会影响 Shell 能不能找到语言工具。
- Java 版本可以验证运行工具是否能执行。
- 监听端口可以观察本地服务入口。

## 7. 今日薄弱点

今天最薄弱的是完整链路：

```text
打开开发工具 → 进入项目目录 → 执行命令 → 工具读取配置和环境 → 程序启动 → 服务监听端口 → localhost 访问
```

这部分不是单个概念，而是 Day15、Day16、Day17 的综合题，后面 Week03 复习时要重点重讲。

## 8. 今日复盘

今天真正建立的是“开发环境是组合”的意识。以后遇到项目跑不起来，不能只问“软件装了吗”，还要检查项目目录、语言工具、运行时、环境变量、配置文件、端口、权限、依赖、日志和错误信息。

最重要的一句话：

```text
开发环境是让项目可以被识别、启动、运行和访问的一整套条件。
```
