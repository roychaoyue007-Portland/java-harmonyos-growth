# Day 17 练习答案：开发环境组成

## 验收题原始回答

1、由操作系统，ide，java环境，项目，配置文件

2、编辑器是单纯进行代码编辑的位置，ide一般可以集成开发环境

3、语言工具解决代码编辑环境的问题；运行时解决特定语言编译的问题

4、因为程序或者工具运行在不同目录下结果不同

5、环境变量是找到程序，配置文件是告诉怎么用

6、本地服务是计算机本地的服务

7、本机网络接口

8、因为服务依赖端口监听，相关端口被占用，对应的服务如果无法主动变更端口，那么监听就无法生效，服务也就无法启动

9、是否安装程序，是否配置环境，程序版本是否正确

10、说实话还是没理解，可以记为本周复习的重点

## 订正版答案

1、开发环境通常由操作系统、编辑器或 IDE、语言工具、运行时、项目目录、配置文件、环境变量、本地服务和日志等部分组成。

2、编辑器主要用于编辑代码；IDE 通常集成编辑、项目识别、运行、调试、配置管理和错误提示等能力。

3、语言工具负责处理代码或启动程序，例如编译、运行、格式化、检查版本；运行时负责支撑程序真正运行，例如 JVM 支撑 Java 程序运行。

4、项目目录会影响程序或工具运行，因为很多工具会以当前目录作为起点去查找代码、配置文件、依赖、输出目录和相对路径。同一个命令在不同目录下执行，可能找到的文件不同，所以运行结果也不同。

5、环境变量提供系统或当前环境级的信息，PATH 负责帮助 Shell 查找外部命令；配置文件告诉某个程序或项目应该按什么规则工作。

6、本地服务是运行在当前电脑上的服务程序，它可能作为进程在后台运行，并监听某个本地端口。

7、`localhost:8080` 表示访问当前电脑上 8080 端口对应的服务入口。

8、服务依赖端口监听。如果端口被占用，服务无法成功监听该端口，也就可能无法启动或无法提供访问入口。

9、检查开发环境时，可以看程序是否安装、语言工具是否能执行、版本是否正确、环境变量是否正确、项目目录是否正确、配置文件是否存在、端口是否被占用、权限和依赖是否满足。

10、打开开发工具，就是启动一个程序；进入项目目录，是告诉工具当前要处理哪个项目；执行命令后，Shell 会根据 PATH 找到对应工具；工具再读取参数、配置文件、环境变量和项目文件；程序启动后变成进程；如果它是服务程序，还会监听本地端口；之后可以通过 localhost:端口访问它。
