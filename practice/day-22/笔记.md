# Day 22 练习笔记：CPU、内存、硬盘、操作系统与进程

## 1. 今日主题

操作系统如何管理程序运行：CPU、内存、硬盘、程序文件与进程之间的关系。

## 2. 今日核心问题

一个程序从硬盘上的文件变成正在运行的进程时，CPU、内存、硬盘和操作系统分别做了什么？

## 3. 今日理解

程序文件平时是静态保存在硬盘上的内容。它可能是可执行文件、代码文件、配置文件或项目文件，但只要没有被启动，它就还不是进程。

程序启动时，操作系统会创建进程，给它分配进程 ID 和运行所需资源。内存提供运行空间，CPU 在操作系统调度下执行进程中的指令。

服务、本地端口和 localhost 都建立在“进程已经运行”的基础上。服务程序启动后可能成为服务进程，并监听端口等待请求。

## 4. 安全观察命令

```powershell
Get-Location
Get-Process | Select-Object -First 10
Get-Process | Sort-Object CPU -Descending | Select-Object -First 10 Name,Id,CPU,WorkingSet
Get-Process | Sort-Object WorkingSet -Descending | Select-Object -First 10 Name,Id,CPU,WorkingSet
Get-CimInstance Win32_OperatingSystem | Select-Object TotalVisibleMemorySize,FreePhysicalMemory
Get-Volume
Get-Command java
java -version
Get-NetTCPConnection -State Listen | Select-Object -First 10 LocalAddress,LocalPort,State,OwningProcess
```

## 6. 今日重点

1. `Get-Process` 看到的是正在运行的进程。
2. PID 是进程编号，用来区分不同进程。
3. `WorkingSet` 可以粗略理解为进程当前占用的一部分物理内存。
4. 硬盘容量和内存容量不是同一个概念。
5. 程序文件存在，不代表程序已经运行。
6. 进程存在，说明程序已经被操作系统启动成运行实例。
