# Day 22 练习答案：CPU、内存、硬盘、操作系统与进程

## 1. 命令观察整理

### `Get-Process`

作用：查看当前正在运行的进程。

需要记住：它看到的是进程，不是硬盘上的全部程序文件。

### `Get-Process | Sort-Object CPU -Descending`

作用：按 CPU 累计使用情况排序进程。

需要记住：CPU 数值反映进程使用 CPU 的累计情况，不代表程序文件大小。

### `Get-Process | Sort-Object WorkingSet -Descending`

作用：按进程当前占用的一部分物理内存大小排序。

需要记住：`WorkingSet` 可以粗略理解为进程当前占用的内存量。

### `Get-CimInstance Win32_OperatingSystem`

作用：查看操作系统层面的内存信息。

需要记住：内存是运行时资源，不等于硬盘容量。

### `Get-Volume`

作用：查看磁盘卷和硬盘空间。

需要记住：硬盘主要用于长期保存文件、程序和数据。

### `Get-Command java`

作用：查看 PowerShell 能否找到 `java` 命令以及找到的位置。

需要记住：这一步检查的是命令查找，不等于 Java 程序已经长期运行。

### `java -version`

作用：启动 Java 程序，让它输出版本信息。

需要记住：执行这条命令时，会短暂启动 Java 进程并输出结果。

### `Get-NetTCPConnection -State Listen`

作用：查看正在监听端口的 TCP 连接信息。

需要记住：`OwningProcess` 是占用某个监听端口的进程 ID。

## 2. 程序运行链路

```text
程序文件在硬盘上
→ 用户双击或输入启动命令
→ Shell / IDE / 操作系统找到程序入口
→ 操作系统加载运行所需内容
→ 操作系统创建进程并分配 PID
→ 进程占用内存等资源
→ CPU 在调度下执行进程中的指令
→ 服务类进程可能监听端口等待请求
```

## 3. 今日易混淆点整理

### 文件存在和程序运行

文件存在只说明硬盘里有程序文件。程序运行说明操作系统已经创建了进程。

### 内存和硬盘

硬盘负责长期保存；内存负责运行时临时空间。

### CPU 和进程

CPU 更准确地说是执行进程中的指令，而不是执行“进程”这个名词。

### 后台进程和静态文件

后台进程虽然没有明显窗口，但仍然是运行中的。静态的是程序文件，不是进程。

## 4. 最终整理答案

一个程序平时以文件形式静态保存在硬盘上。启动时，操作系统会加载程序所需内容，创建进程并分配 PID、内存等资源。CPU 在操作系统调度下执行进程中的指令。如果这个程序是服务，运行后还可能监听端口，等待客户端请求。
