# Day 21 练习笔记：Week03 复盘

## 1. 今日主题

Week03 复盘：计算机与开发环境基础衔接。

今天不是学习新主题，而是把 Day15 到 Day20 的内容串起来。


## 3. 本周关键理解

1. 程序文件是静态的，进程是运行起来的程序实例。
2. 打开项目只是查看和识别文件，运行项目才会尝试创建进程。
3. 程序文件存在不代表一定能运行，还要看运行时、配置、环境变量、路径、权限、依赖等条件。
4. 本地服务启动后会成为进程，需要访问时通常会监听端口。
5. localhost 表示当前电脑，`localhost:端口` 表示访问当前电脑上某个端口的服务入口。
6. 排错要先看完整错误信息和日志，再按层次缩小范围。

## 4. 本周薄弱点

1. 开发环境组成需要完整记忆。
2. 服务、进程、监听端口和 localhost 的关系需要持续巩固。
3. `OwningProcess` 要记成“占用端口的进程 ID”。
4. 服务不是静态进程。
5. IDE 内部运行项目可能使用 IDE 自己配置的运行环境，不一定只靠 PATH。

## 6. 今日复盘

Week03 真正建立的是“本地开发环境是一条链路”的意识。以后遇到项目跑不起来或 localhost 访问失败，不能只说报错了，也不能直接猜端口被占用，而要按证据一步步查。

最重要的一句话：

```text
本地项目能访问，是程序文件、启动命令、工具、运行条件、进程、端口和访问地址共同成立的结果。
```
