# Day 24 练习答案：操作系统权限、用户和进程访问资源

## 1. 命令整理

### `whoami`

作用：查看当前执行命令的用户身份。

需要记住：当前用户会影响命令和进程能访问哪些资源。

### `Set-Content`

作用：向文件写入内容。

需要记住：路径正确不代表一定能写入，还要看当前用户是否有写入权限。

### `Get-Content`

作用：读取文件内容。

需要记住：文件存在不代表当前用户或进程一定有读取权限。

### `Get-Item`

作用：查看文件对象及其属性。

需要记住：属性可以帮助观察文件位置、大小、时间和基本状态，但不等于完整权限分析。

### `Get-NetTCPConnection -State Listen`

作用：查看正在监听的 TCP 端口。

需要记住：`OwningProcess` 是占用监听端口的进程 ID。

### `Get-Process -Id 进程ID`

作用：根据进程 ID 反查进程。

需要记住：如果反查失败，要记录错误信息，不要强行结束陌生进程。

## 2. 权限检查链路

```text
当前用户运行命令
→ 命令对应程序被操作系统创建为进程
→ 进程尝试访问文件、目录、端口或网络连接
→ 操作系统检查资源是否存在
→ 操作系统检查当前身份是否有权限
→ 操作系统检查资源状态是否可用
→ 允许访问或返回错误信息
```

## 3. 错误区分

### 路径不存在

表示目标路径或文件本身找不到。排查时先检查路径是否写错、当前目录是否正确、文件是否真的存在。

### 权限不足

表示目标资源可能存在，但当前用户或进程没有读取、写入、执行或访问它的权限。

### 端口访问失败

端口或服务相关访问失败可能来自多个层次：

- 服务没有监听目标端口。
- 访问地址或路径写错。
- 端口被其他进程占用。
- 防火墙或安全规则阻止访问。
- 服务虽然启动但内部报错。

## 4. 最终整理答案

用户运行命令后，命令会拉起进程。进程访问资源时，操作系统会检查资源是否存在、路径或地址是否正确、当前用户是否有权限、资源状态是否可用。文件存在不代表能读取，路径正确不代表能写入，端口或服务存在也不代表访问一定成功。
