# Day 16 练习笔记：程序运行条件

## 1. 今日主题

程序运行条件：参数、配置文件、环境变量、路径与依赖。

今天接在 Day15 后面：Day15 讲程序如何启动并变成进程，Day16 讲程序启动后能不能正常运行，还要看哪些条件。

## 2. 核心主线

```text
程序文件存在
↓
程序可以被启动
↓
程序读取参数、配置文件、环境变量
↓
程序访问路径、文件、端口或外部依赖
↓
如果条件满足，程序正常运行
↓
如果条件不满足，程序输出错误信息或日志
```

## 3. 参数、配置文件、环境变量

### 参数

参数是这次运行时临时传给程序的信息。

例子：

```powershell
java -version
Get-ChildItem -Path . -File
```

### 配置文件

配置文件保存长期规则，例如端口、日志位置、默认路径等。

### 环境变量

环境变量是系统或当前环境提供的键值对配置。PATH 是环境变量的一种，用于帮助 Shell 查找外部命令。

## 4. 常见运行条件问题

| 问题 | 说明 | 检查方向 |
| --- | --- | --- |
| 参数错误 | 命令写法或参数值不对 | 看帮助、看错误信息 |
| 配置缺失 | 程序需要配置但没有找到 | 查配置文件路径 |
| 环境变量错误 | 程序读取到错误环境信息 | 查 `$env:PATH`、`$env:JAVA_HOME` |
| 路径不存在 | 相对路径或目标文件不存在 | `Get-Location`、`Test-Path` |
| 权限不足 | 当前用户或程序没有访问权限 | 看错误信息中的 permission/access |
| 端口占用 | 服务需要的端口已被占用 | `Get-NetTCPConnection -State Listen` |
| 依赖缺失 | 程序需要的工具、库或服务不存在 | 查运行环境和日志 |

## 5. 今日命令观察

建议观察命令：

```powershell
java -version
Get-ChildItem -Path . -File
Get-ChildItem -Path . -Directory
Get-Location
Get-ChildItem .
Get-ChildItem ..
Test-Path .\abc.txt
Resolve-Path .
$env:PATH
$env:JAVA_HOME
Get-Command java
Get-NetTCPConnection -State Listen | Select-Object -First 10
not-a-real-command
Get-Content .\not-exist-file.txt
```

观察重点：

- 参数会改变命令行为。
- 当前目录会影响相对路径。
- PATH 是环境变量，但不是所有环境变量都是 PATH。
- 命令找不到和路径找不到是不同问题。
- 服务启动失败可能和端口占用有关。

```text
我执行的命令：

我猜测的原因：
我用什么命令验证：
验证结果：
```

## 7. 今日薄弱点

1. 环境变量不是只用来找应用，PATH 才负责命令查找。
2. PATH 不能保证程序启动成功。
3. 程序启动后通常读取参数、配置文件、环境变量、路径和依赖，而不是再通过 PATH 找自己。
4. 权限不足不一定只发生在进程启动前，也可能发生在运行过程中的某一步。

## 8. 今日复盘

今天真正理解的是：程序是否正常运行，不能只看程序文件是否存在。程序运行需要一组条件：参数、配置、环境变量、路径、权限、端口和依赖。排错时要先看错误信息，再判断是哪一类运行条件不满足。

最重要的一句话：

```text
PATH 只帮助 Shell 找命令；程序能不能正常运行，还要看参数、配置、环境变量、路径、权限、端口和依赖。
```
