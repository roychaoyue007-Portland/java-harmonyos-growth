# Day 23 练习答案：文件读写与程序输入输出

## 1. 命令整理

### `Get-Content`

作用：从文件中读取内容。

需要记住：文件在硬盘上，不等于程序已经读到了它；执行读取动作后，文件内容才进入程序或命令。

### `Set-Content`

作用：把内容写入文件，并覆盖原有内容。

需要记住：`Set-Content` 更适合创建或重写一个文件内容。

### `Add-Content`

作用：把新内容追加到文件末尾。

需要记住：`Add-Content` 不会直接清空原有内容，而是在后面继续加。

### `Write-Output`

作用：产生输出，默认显示在终端，也可以进入管道。

需要记住：终端显示只是临时展示，不等于保存到文件。

### `Out-File`

作用：把命令输出写入文件。

需要记住：它可以改变输出去向，把本来显示在终端的结果保存到硬盘文件。

### 管道 `|`

作用：把上一条命令的输出交给下一条命令作为输入。

需要记住：管道解决命令之间的数据传递问题。

## 2. 数据流整理

```text
文件保存在硬盘上
→ 程序或命令读取文件
→ 文件内容成为输入
→ 程序处理数据
→ 结果输出到终端、文件、管道或网络
```

## 3. 错误观察整理

当执行：

```powershell
Get-Content .\practice\day-23\not-exist.txt
```

如果文件不存在，PowerShell 会输出错误信息。

需要记录：

```text
我执行了什么：
Get-Content .\practice\day-23\not-exist.txt

程序想读取哪个文件：
.\practice\day-23\not-exist.txt

最可能原因：
文件不存在，或当前目录不对。

怎样验证：
Test-Path .\practice\day-23\not-exist.txt
Get-Location
Get-ChildItem .\practice\day-23
```

## 4. 今日易混淆点

### 文件存在和文件输入

文件存在只表示硬盘上有数据。文件输入表示程序已经执行读取动作，把文件内容取进来。

### 终端输出和文件输出

终端输出用于展示，文件输出用于保存。显示在终端不会自动保存到硬盘。

### 正常输出和错误输出

正常输出是程序按预期产生的结果。错误输出是程序失败时给出的线索，常用于排错。

## 5. 最终整理答案

输入是进入程序的数据，输出是程序处理后的结果。程序可以从文件、终端或网络获得输入，也可以把结果显示到终端、写入文件或传给其他程序。`Get-Content` 读取文件，`Set-Content` 覆盖写入，`Add-Content` 追加写入，`Out-File` 把输出保存到文件，管道把输出交给下一条命令。
