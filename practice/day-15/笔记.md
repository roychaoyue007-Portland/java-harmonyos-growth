# Day 15 练习笔记：程序启动链路

## 1. 今日主题

开发环境里的程序启动链路：从双击软件或输入命令，到操作系统创建进程。

今天仍然属于 Month 01 的计算机基础，不进入 Java 语法。

## 2. 核心流程

```text
用户发起启动
↓
系统或 Shell 找到程序文件
↓
操作系统加载程序
↓
分配内存和运行资源
↓
创建进程
↓
程序开始执行
↓
读取参数、配置或环境变量
↓
产生正常输出、错误信息或日志
```

## 3. 关键概念

### 程序文件

程序文件是存放在硬盘上的静态内容，例如 `java.exe`、`powershell.exe` 或某个桌面软件的可执行文件。

### 进程

进程是程序运行起来之后的实例。程序文件可以一直存在，但只有启动后才会有进程。

### PATH

PATH 是环境变量，它的值是一串目录。Shell 通过 PATH 查找外部命令对应的程序文件。

### 启动失败

启动失败可能发生在不同阶段：命令找不到、路径找不到、参数错误、配置缺失、权限不足、端口占用、依赖缺失等。

## 4. 今日命令观察建议

```powershell
Get-Location
Get-ChildItem
Get-Command powershell
Get-Command java
Get-Process | Select-Object -First 10
Get-Process java -ErrorAction SilentlyContinue
java -version
$LASTEXITCODE
not-a-real-command
Get-Content .\not-exist-file.txt
```

这些命令分别用于观察：

- 当前目录。
- 当前目录下的文件和目录。
- 命令对应的程序位置。
- 当前运行中的进程。
- Java 版本命令是否可启动。
- 外部程序退出状态。
- 命令找不到和路径找不到的区别。

## 5. 安全错误分类

| 命令 | 更像哪类问题 | 先检查什么 |
| --- | --- | --- |
| `not-a-real-command` | 命令找不到 | 命令名、PATH、Get-Command |
| `Get-Content .\not-exist-file.txt` | 路径或文件找不到 | 当前目录、Test-Path、文件是否存在 |
| `java -version` 失败 | 可能是 PATH、安装或 Java 启动问题 | Get-Command java、where.exe java、错误信息 |

## 7. 今日薄弱点

1. PATH 不是万能的。它只帮助 Shell 找外部命令。
2. 命令能找到，不代表程序能成功运行。
3. 程序启动链路不止“找到程序、分配内存”，还包括加载、创建进程、读取参数和配置、输出或报错。
4. 排错不能只说“按报错定位”，要保留完整错误信息并明确验证步骤。

